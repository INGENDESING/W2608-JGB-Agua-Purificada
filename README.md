# W2608 — Diagnóstico del Sistema de Tratamiento y Distribución de Agua Purificada y Distribución JGB

Portal y repositorio técnico del proyecto **W2608** para el diagnóstico del sistema de tratamiento, almacenamiento intermedio (`3.000 L`) y distribución de agua purificada en los cuatro anillos de proceso (**Farma**, **Cosméticos**, **Suplementos** y **PW**) de **JGB** en Cali, Colombia.

- **Portal Web Técnico (GitHub Pages):** [https://ingendesing.github.io/W2608-JGB-Agua-Purificada/](https://ingendesing.github.io/W2608-JGB-Agua-Purificada/)
- **Dirección del Proyecto:** Javier Micolta (`J.Micolta`)
- **Ingeniería Especialista:** MSc Jonathan Arboleda (`J.Arboleda` · Identidad gráfica `JAGDESING`)
